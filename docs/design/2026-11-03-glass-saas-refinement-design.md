# 第一套皮肤轻玻璃 SaaS 风格修订设计

> 日期：2026-11-03
> 状态：按用户视觉修订要求已编码，待实际界面验收
> 范围：FrostNote 第一套 `glass` 皮肤的 Windows 桌面端与 Android 手机端
> 依据：用户提供的 rondesignlab 风格描述与组件、移动端提示词

## 1. 背景与目标

先前的 Glass Card 方案以高饱和便签色铺满卡片，并使用明显高光、描边和网格。它与这次明确的商用 SaaS 风格要求冲突。本设计修订已确认的 `2026-11-03-glass-card-first-skin-design.md` 中第 4 节的视觉方案，以及后续实现文档对应的样式和材质方案；皮肤身份、数据兼容和业务功能继续沿用。

目标是让第一套皮肤呈现适合代码工具和管理面板的安静、实用界面：中性底色、留白、统一大圆角、轻薄磨砂、极轻颗粒、浅层软阴影，以及少量低饱和青色强调。设置页中文名称改为「轻玻」，保留 `glass` 标识。桌面优先校准，手机端使用同一套视觉规则。深色与浅色均需完整适配。

### 成功标准

| 项目 | 验收方式 |
| --- | --- |
| 组件形状 | 桌面第一套皮肤的卡片、弹窗、输入框和矩形按钮统一使用 20px 圆角，手机端仍为 16px；独立便签和窄窗口控件无直角或裁切 |
| 材质 | 表面有低对比半透明层、细边和轻微背景模糊；无厚玻璃、立体内凹/外凸、黏土感或强高光 |
| 色彩 | 页面与卡片主要为白、浅灰或深色中性面；便签色仅用于色点、细条、标签或小块操作反馈，整卡不铺高饱和色 |
| 阴影与纹理 | 多层浅阴影只帮助分层；颗粒在正常观看距离下不形成可辨识斑点或阅读干扰 |
| 信息层级 | 标题较粗、正文较轻，间距和行高舒适；列表、设置、编辑、弹窗可快速扫描与操作 |
| 兼容 | 三套皮肤、8 种便签色、`cursor` 到 `glass` 的迁移、透明度、编辑、搜索、同步保持原行为 |

## 2. 非目标

- 不复刻某一张 Instagram 图片的像素位置。当前依据是用户给出的文字规范；若后续提供具体作品截图，可再做逐屏对照。
- 不引入新皮肤 ID、字体包、原生毛玻璃依赖，也不修改数据库、同步协议或便签色存储值。
- 不修改 Vellum、Mote 的视觉语言，不重排列表信息架构或新增装饰插画。
- 不对独立 Electron 透明便签承诺模糊 Windows 桌面壁纸。网页内弹窗可做背景模糊，独立窗口用轻透明材质近似。

## 4. 视觉规范

### 4.1 色彩与信息密度

- 浅色：近白中性页面，白灰半透明表面，深灰文字。深色：中性炭灰页面，略浅灰表面，近白文字。底色不使用彩色光斑或可见网格。
- 桌面浅色模式按用户提供的参考图提高明度对比：画布使用冷灰蓝 `#E6EBF1`，列表卡片使用更深的蓝灰 `#CFDDE4`，独立便签沿用同层级的中性底，文字为石墨色。青色与淡紫仅作为小面积反馈和预览色；不移植图片中的大面积光晕或高饱和渐变。手机端保留现有轻玻璃配色。
- 桌面浅色卡片上的正文、辅助文字和青色操作文字按最终卡片底色检查对比度；辅助文字和强调文字至少达到 4.5:1，避免蓝灰材质压低可读性。
- 桌面深色模式借用参考图的深石墨与蓝灰玻璃关系：画布 `#1D242C`、卡片 `#2E3E4A`，柔和青色与淡紫只用于强调；不加入图片中的黑色光斑和明显发光。桌面皮肤预览单独使用这组颜色，手机端预览与主题值保持原样。
- 交互主色使用低饱和青色；只在主按钮、焦点环、选中态和重点小标签出现。错误、警告继续使用语义色，但控制面积。
- 8 种便签色继续存在于数据和选择器；列表卡片只显示 2–4px 标识或小色点，独立便签/手机编辑页可在标题区使用小面积色标。内容表面始终中性，便于阅读用户自定义文字色和 AI 标注。
- 不新增大面积渐变、发光、漂浮装饰物、卡通插画或拟物按压效果。保留功能所需图标与状态提示。

### 4.2 圆角、材质与阴影

- 桌面第一套皮肤的卡片、弹窗、输入框、按钮和独立便签统一使用 20px 基准圆角；手机端仍为 16px。圆形图标按钮和色点保持圆形。小标签可使用同一圆角值形成胶囊，但不以大面积胶囊替代命令按钮。
- 轻玻璃表面采用弱透明的中性色、约 1px 低透明边线和 8–12px 背景模糊；不提高背景饱和度。Android 不支持模糊或长列表性能敏感时使用视觉接近的预合成中性色。
- 阴影使用两层低透明软阴影：近处轻微边界、远处低对比扩散。深色模式也避免黑色重投影；焦点与选中主要靠边框和浅色块识别。
- 颗粒仅覆在第一套皮肤的非文本背景层，透明度从几乎不可见的水平开始校准；装饰层不拦截输入。若设备缩放或低分辨率导致可见噪点，直接降低或关闭，不牺牲清晰度。

### 4.3 排版与空间

- 桌面沿用系统无衬线字体优先级；标题用 600–700 字重，正文 400–500，辅助信息更轻。手机使用平台系统无衬线字体。字距保持自然、略宽松的阅读感，通过行高和间距建立层级，不依赖夸张字号。
- 列表和后台式设置界面优先扫描效率。设置区块采用无框分组，仅可选择项目保留圆角卡片；区块之间留足空隙，卡片内部保持紧凑；不增加营销式首屏、嵌套装饰卡或解释性文案。
- 窄至 160px 的独立便签仍能容纳标题栏工具，交互目标和内容布局不因圆角或阴影改变尺寸。

## 5. 端到端呈现

### 桌面端

1. 列表与设置：中性画布和轻表面；便签卡片不再按颜色整面着色，仅保留小色标。搜索、筛选、设置选项和弹层使用统一圆角、边线、浅阴影。
   默认列表采用参考图的主次卡片节奏：当前排序第一张便签跨两列成为深石墨主卡，其余以双列紧凑卡展示。搜索或筛选时恢复等规格结果卡，方便逐条比较；卡片操作、标签和待办进度继续可用。无独立装饰图形或发光背景。
2. 独立便签：窗口保留 `Sticker.opacity` 的背景透明语义；轻薄中性底与小面积便签色标区分便签。文字和工具栏不随背景透明度降低。标题栏可拖动，折叠态和 160px 宽度仍可用。
3. 菜单与对话框：页面内浮层使用轻微 `backdrop-filter`；透明便签窗口不模拟系统桌面实时模糊。深色组件遵守用户给出的单组件提示词。

### 手机端

1. 列表、编辑、设置共享中性底色、16px 圆角和低饱和青色主操作。列表卡继续关闭逐卡实时模糊，仅使用轻薄预合成表面。
2. 编辑器 WebView 保持可读实色；便签色只在色标、选择器或小面积状态出现。少量浮层由 `GlassSurface` 使用设备可用的轻模糊；Android 31 以下回退预合成表面。
3. 手机文案和布局以真实工具界面为准；用户提示词里的 iPhone 样机仅表达风格，不改变本项目 Android 平台范围。

## 6. 模块职责与接口

| 模块 | 职责 |
| --- | --- |
| `src/shared/skins.ts` | 更新第一套皮肤名称说明、预览色与统一圆角；保留 ID 和迁移规则 |
| `src/shared/palette.ts` | 提供便签色的小面积标识色；不再把高饱和色用于第一套卡片背景 |
| `src/renderer/styles/{tokens,globals,sticker}.css` | 定义桌面轻玻璃 token、组件材质和独立便签样式；Vellum/Mote 限定规则继续独立 |
| `src/renderer/components/*` | 列表、编辑、设置、通用按钮/输入/弹窗消费统一 token，不复制材质计算 |
| `mobile/src/theme.tsx` | 第一套浅/深色 token、圆角、低饱和强调色和背景效果 |
| `mobile/src/components/{ScreenBackground,GlassSurface,StickerCard,GrainOverlay}.tsx` | 手机背景、材质、列表颜色标识和轻颗粒；性能回退留在表面组件 |
| `mobile/src/screens/{StickerEditorScreen,SettingsScreen}.tsx` | 编辑外壳、颜色选择和皮肤预览消费主题值 |

`SkinId` 仍是 `glass | vellum | mote`，`Sticker.color` 与 `Sticker.opacity` 的类型和持久化格式不变。无新增 HTTP、IPC、SQLite 或数据库字段。旧 `cursor` 设置仍归一化为 `glass`，升级和同步不需要数据迁移。

## 7. 边界、风险与回退

- 便签透明度降至 20% 时，复杂桌面背景可能降低窗口边界可见性；正文和操作区应保持不透明前景与足够衬底，并在深浅壁纸上检查。
- 深色轻玻璃容易因过低对比而丢失分层；依靠边线、层级间距和细微明度差区分，常规文字按 WCAG AA 核对。
- 圆角统一后，窄窗口工具栏、下拉菜单和手机小屏可能溢出；以固定控件尺寸和内容换行处理，不临时缩小圆角。
- 背景模糊与颗粒均为渐进增强。低性能 Android、减少动态效果或低分辨率下可降低强度，业务操作必须保持可用。
- Vellum/Mote 样式按 `data-skin` 或主题分支隔离，避免第一套材质改动波及另两套。

## 8. 验证策略

1. 静态：桌面和手机 TypeScript 检查、Electron 构建、Android 构建；检查样式选择器只影响 `glass`。
2. 视觉：先校准桌面列表、独立便签和设置，再核对卡片、弹窗、输入框、按钮的深浅模式，最后核对 Android 列表、编辑与设置。每个视图检查圆角、色彩面积、颗粒、阴影、文字层级和控件遮挡。
3. 交互：切换三套皮肤、8 色选择、搜索高亮、AI 标注、富文本输入与保存、弹窗菜单、折叠与拖动、20%–100% 透明度。
4. 性能与兼容：Android 长列表滚动、旧设备模糊回退、旧 `cursor` 偏好读取、旧便签色和跨端同步。无连接设备时明确记录实机视觉与交互未验证。

## 9. 实施依据

本次修订按用户对当前桌面效果的明确纠偏和此前“开始编码”的授权实施。第一套 `glass` 从“整张彩色玻璃卡”改为“中性、轻薄的 SaaS 毛玻璃界面”，桌面和 Android 同步调整；便签色只作为小面积标识，矩形表面和控件使用统一 16px 圆角。实际视觉效果仍需在运行窗口和 Android 设备上验收。
