# PRD · StickerNote — 桌面便签应用（Electron）

> 版本：v1.0 · 撰写人：许清楚（PM）· 日期：2026-06-02

---

## 1. 产品概述

### 1.1 项目信息

| 项目 | 内容 |
|------|------|
| 产品名称 | StickerNote |
| 平台 | Windows 桌面（Electron） |
| 技术栈 | Electron + React + Vite + MUI + Tailwind CSS |
| 数据存储 | 本地 JSON / electron-store |
| 版本目标 | v1.0.0 MVP |

### 1.2 背景与目标

StickerNote 是一款运行在 Windows 桌面的轻量便签工具，旨在替代物理便利贴，帮助用户随时在屏幕上记录想法、任务与提醒，无需打开浏览器或重型文档工具。

**三大产品目标：**

1. **即用即记**：启动快、创建快，最低摩擦地完成信息捕获。
2. **常驻可见**：便签始终悬浮桌面，不被其他窗口遮盖，保持信息可见性。
3. **有序管理**：多张便签可分色、打标签、集中搜索，从"乱贴"升级为结构化知识管理。

### 1.3 目标用户

- **上班族 / 知识工作者**：需要在电脑前频繁记录临时信息、会议要点、待办事项。
- **学生**：多任务学习时需要可视化提醒与分类笔记。
- **创意工作者**：脑暴灵感时需要快速落地、颜色区分不同主题。

### 1.4 核心价值主张

> "开机即在，随手一贴；颜色分类，一目了然。"

## 3. 功能需求池

### P0 · 必须实现（Must Have）

#### F-01 新建便签
- **描述**：点击系统托盘图标或使用快捷键，立即创建一张新便签窗口。
- **验收标准**：
  - 新建便签在当前屏幕可见区域内出现（避免超出屏幕边界）。
  - 多次新建时，后续便签在前一张基础上偏移 20px，避免完全重叠。
  - 创建时间 ≤ 300ms（主进程到窗口可见）。

#### F-02 富文本编辑
- **描述**：便签内置富文本编辑器，支持基础格式化操作。
- **验收标准**：
  - 支持加粗（Ctrl+B）、斜体（Ctrl+I）。
  - 支持有序列表和无序列表。
  - 支持 5 档以上字号切换（12 / 14 / 16 / 20 / 24px）。
  - 格式化操作通过工具栏按钮或快捷键均可触发。
  - 富文本内容保存后重启仍保留格式。

#### F-03 自动保存
- **描述**：用户停止输入 500ms 后自动持久化便签内容。
- **验收标准**：
  - 内容变更后 ≤ 500ms 写入本地存储。
  - 应用崩溃重启后，所有便签内容与格式完整恢复。
  - 不因频繁写入导致明显卡顿（写入操作异步执行）。

#### F-04 多便签管理
- **描述**：支持同时开启多张独立便签窗口，可自由拖动。
- **验收标准**：
  - 每张便签为独立 Electron BrowserWindow。
  - 拖动便签窗口到任意屏幕位置后，位置数据持久化保存。
  - 重启后各便签恢复到上次关闭时的位置和尺寸。
  - 最大支持同时打开 20 张便签（无明显性能下降）。

#### F-05 隐藏 / 删除
- **描述**：便签窗口可关闭（隐藏）或彻底删除。
- **验收标准**：
  - 点击关闭按钮为"隐藏"，便签数据保留，可从列表面板恢复显示。
  - 从列表面板明确点击"删除"按钮并确认后，便签数据被彻底清除。
  - 删除操作弹出确认对话框，防止误删。

#### F-06 换色主题
- **描述**：每张便签可独立设置背景色主题。
- **验收标准**：
  - 提供至少 8 种颜色选项：黄、蓝、绿、粉、橙、紫、白、灰。
  - 颜色切换即时生效，无需重启便签窗口。
  - 颜色选择持久化保存，重启后恢复。

### P1 · 推荐实现（Should Have）

#### F-07 便签列表面板
- **描述**：独立的管理面板，展示所有便签（含隐藏便签）并支持搜索。
- **验收标准**：
  - 列表显示每条便签的：颜色、标题（内容前 20 字）、创建时间、状态（显示 / 隐藏）。
  - 搜索框支持实时过滤，匹配便签全文内容。
  - 点击列表项可定位 / 唤起对应便签窗口。
  - 面板支持通过系统托盘菜单或全局快捷键打开。

#### F-08 标签分类
- **描述**：为便签添加自定义标签，支持按标签过滤。
- **验收标准**：
  - 用户可在便签窗口或列表面板为便签添加 / 删除标签。
  - 标签支持自由输入（无预设限制）。
  - 列表面板提供标签过滤器，点击标签名只显示该标签下的便签。
  - 同一便签支持多标签。

#### F-09 置顶窗口
- **描述**：将指定便签窗口设为始终在最前。
- **验收标准**：
  - 便签窗口有"置顶"开关按钮（图钉图标）。
  - 开启后，切换到其他应用时该便签窗口仍显示在最前。
  - 置顶状态持久化，重启后恢复。
  - 调用 `win.setAlwaysOnTop(true, 'floating')` 实现。

#### F-10 全局快捷键
- **描述**：注册全局热键，不需聚焦应用即可触发。
- **验收标准**：
  - 默认快捷键：`Ctrl+Alt+N` 新建便签，`Ctrl+Alt+S` 打开列表面板。
  - 快捷键冲突时，应用启动时给出提示并允许用户在设置中修改。
  - 通过 Electron `globalShortcut` API 注册。

#### F-11 透明度调节
- **描述**：为每张便签独立调节窗口透明度。
- **验收标准**：
  - 透明度范围：20% ~ 100%，步长 5%，通过滑块控制。
  - 调节时实时预览效果，松开后保存设置。
  - 低于 30% 时自动显示"不透明度过低"的视觉提示。
  - 通过 `win.setOpacity()` 实现。

#### F-12 撤销 / 重做
- **描述**：富文本编辑器内的撤销 / 重做操作。
- **验收标准**：
  - `Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做。
  - 支持至少 50 步操作历史。
  - 富文本库内置 History 扩展（如 Tiptap history extension）实现。

### P2 · 可选实现（Nice to Have）

#### F-13 提醒闹钟
- **描述**：为便签设置提醒时间，到达时弹出系统通知。
- **验收标准**：
  - 可设置单次提醒（具体日期时间）。
  - 使用 Electron `Notification` API 弹出系统级通知，通知包含便签标题。
  - 提醒触发后，通知标记为已触发，不重复弹出。
  - 应用在后台（托盘）运行时仍可正常触发提醒。

#### F-14 导入 / 导出
- **描述**：批量备份和迁移便签数据。
- **验收标准**：
  - 导出：将所有便签数据导出为单个 `.json` 文件，包含内容、颜色、标签、位置等全部字段。
  - 导入：读取符合格式的 `.json` 文件，支持"合并"（追加）和"覆盖"两种模式。
  - 导入前提示当前数据覆盖风险并要求确认。

#### F-15 待办清单模式
- **描述**：便签支持勾选式 Todo 模式。
- **验收标准**：
  - 可在富文本编辑工具栏切换到"待办清单"模式。
  - 每个待办项前有复选框，勾选后文字自动显示删除线。
  - 已完成项视觉上变灰，未完成项正常显示。
  - 利用 Tiptap TaskList / TaskItem 扩展实现。

#### F-16 深色 / 浅色模式
- **描述**：应用级主题切换，支持跟随系统或手动指定。
- **验收标准**：
  - 三档设置：跟随系统 / 浅色 / 深色。
  - 跟随系统时，监听 `nativeTheme.on('updated')` 事件自动切换。
  - 深色模式下，所有 UI 元素（工具栏、列表面板、设置页）均应用深色配色。
  - 便签背景颜色在深色模式下自动适当加深（10% 亮度降低）。

## 4. UI 设计概要

### 4.1 主要界面

#### 便签窗口（StickerWindow）
```
┌─────────────────────────────────────────┐
│ [颜色选择器] [标签] [置顶📌] [透明度] [×]  │  ← 顶部工具栏（hover显示）
├─────────────────────────────────────────┤
│ [B] [I] [UL] [OL] [✓] [字号▼]           │  ← 富文本工具栏
├─────────────────────────────────────────┤
│                                         │
│   富文本内容区域（可自由输入）            │
│                                         │
│                                         │
└─────────────────────────────────────────┘
│ ↕ 拖拽调整高度                           │
```

- 默认尺寸：240 × 200px，最小 160 × 120px，可自由拖拽调整。
- 顶部工具栏默认隐藏，鼠标悬停时展开（减少视觉干扰）。
- 窗口无系统默认标题栏（`frame: false`），整体圆角设计（8px border-radius）。
- 背景颜色根据所选主题色渲染（默认黄色 `#FFF9C4`）。

#### 便签列表面板（StickerList Panel）
```
┌──────────────────────────────────────────┐
│  📋 StickerNote    [+ 新建]  [设置⚙]     │
├──────────────────────────────────────────┤
│  🔍 搜索便签...                           │
├──────────────────────────────────────────┤
│  标签过滤：[全部] [工作] [学习] [生活] …  │
├──────────────────────────────────────────┤
│  ● 会议记录                  2026-06-01  │
│    下午三点要review代码...    🟡 显示中   │
├──────────────────────────────────────────┤
│  ● 购物清单                  2026-05-30  │
│    牛奶、鸡蛋、面包...        ⚪ 已隐藏   │
└──────────────────────────────────────────┘
```

- 固定宽度 320px，高度跟随内容，最高 600px 可滚动。
- 每条便签展示：颜色圆点、标题（内容前 20 字）、日期、状态标签。
- 右键菜单：显示 / 隐藏、置顶、编辑标签、删除。

#### 系统托盘菜单
```
StickerNote
─────────────────
  📝 新建便签       Ctrl+Alt+N
  📋 便签列表       Ctrl+Alt+S
─────────────────
  ⚙  设置
  ℹ  关于
─────────────────
  ✕  退出
```

#### 设置页（Settings）
- 全局快捷键自定义
- 默认便签颜色
- 深色 / 浅色 / 跟随系统
- 数据导入 / 导出入口
- 开机自启动开关

### 4.2 关键交互逻辑

| 交互 | 行为 |
|------|------|
| 点击便签关闭按钮 | 窗口隐藏（非销毁），数据保留 |
| 拖动便签标题区域 | 移动窗口位置，松手后自动保存坐标 |
| 右键便签顶部栏 | 弹出上下文菜单（复制、导出单张、删除） |
| 双击托盘图标 | 打开 / 关闭便签列表面板 |
| 便签失焦 500ms | 触发自动保存 |
| 拖拽窗口边角 | 调整便签尺寸，最小 160×120px |

## 5. 技术约束

### 5.1 Electron 版本建议

| 项目 | 推荐 |
|------|------|
| Electron | **≥ 28.x**（支持 contextIsolation 默认开启、Fuses API） |
| Node.js | **≥ 20 LTS** |
| Chromium | 随 Electron 28 捆绑的版本（≥ 120） |
| 构建工具 | **electron-builder** ≥ 24.x |

> 选择 Electron 28+ 原因：`win.setOpacity()` 在 Windows 10/11 上稳定，`globalShortcut` 行为一致，nativeTheme API 完善。

### 5.2 主要依赖

| 依赖 | 用途 |
|------|------|
| `electron` | 主框架 |
| `electron-builder` | 打包 / 安装包 |
| `electron-store` | 本地配置 & 便签数据持久化（JSON 格式，存储于 userData） |
| `react` + `vite` | 渲染进程 UI |
| `@mui/material` + `tailwindcss` | UI 组件库 |
| `@tiptap/react` | 富文本编辑器（支持 Bold / Italic / List / TaskList / History） |
| `electron-updater` | 可选：后续版本自动更新 |

### 5.3 数据存储方案

```
userData/
├── stickers.json          # 所有便签数据（主存储）
├── settings.json          # 全局设置（快捷键、主题等）
└── sticker-windows.json   # 各便签窗口的位置 & 尺寸状态
```

**stickers.json 数据结构（示例）：**
```json
{
  "stickers": [
    {
      "id": "uuid-v4",
      "content": "<p><strong>会议记录</strong></p>...",
      "color": "#FFF9C4",
      "tags": ["工作", "会议"],
      "isPinned": false,
      "isVisible": true,
      "opacity": 1.0,
      "reminder": null,
      "createdAt": "2026-06-01T10:00:00Z",
      "updatedAt": "2026-06-02T08:30:00Z",
      "windowState": {
        "x": 100, "y": 200,
        "width": 240, "height": 200
      }
    }
  ]
}
```

### 5.4 打包要求

| 目标 | 规格 |
|------|------|
| 平台 | Windows 10 / 11（x64） |
| 安装包格式 | NSIS Installer（`.exe`）+ 便携版（`.zip`） |
| 开机自启动 | 通过 `app.setLoginItemSettings()` 实现 |
| 图标 | 256×256 `.ico` 格式（系统托盘 + 安装包） |
| 安装包大小目标 | ≤ 120MB（打包时排除 devDependencies） |
| 代码签名 | MVP 阶段暂不要求，正式发版建议添加 |

### 5.5 安全约束

- 渲染进程启用 `contextIsolation: true`，`nodeIntegration: false`。
- 主进程与渲染进程通过 `ipcMain` / `ipcRenderer` + `contextBridge` 通信。
- 文件读写操作仅限 `userData` 目录，禁止渲染进程直接访问 Node.js fs 模块。

## 6. 待确认问题

| # | 问题 | 影响范围 | 优先级 |
|---|------|---------|-------|
| Q1 | 便签数据是否需要支持**云同步**（如 OneDrive / 自定义服务器）？MVP 阶段仅本地存储，后续扩展需预留接口。 | 数据层架构 | 高 |

| Q3 | 富文本编辑器是否需要支持**图片粘贴 / 插入**？Tiptap Image 扩展可快速接入，但会显著增加存储体积。 | F-02 范围 | 中 |
| Q4 | P2 功能（提醒、导入导出、待办、深色模式）是否纳入本期开发，还是作为 v1.1 规划？ | 排期 & 资源 | 高 |
| Q5 | 全局快捷键默认值（`Ctrl+Alt+N`）是否已确认不与常用软件（如 VS Code、Notion）冲突？ | F-10 | 低 |
| Q6 | 应用是否需要**多语言（i18n）**支持？MVP 暂定简体中文，国际化改造成本较高需提前决策。 | UI 全局 | 低 |
